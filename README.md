# basketball-tracking-ml3

Machine learning III project focused on player detection and multi object tracking in basketball broadcast videos.

## Project goal

The goal of this project is to build a computer vision pipeline capable of:

- Detecting basketball players in broadcast videos
- Tracking players across frames
- Assiging consistent IDs to players
- Visualizing player trajectories and tracking results

## Methods

- YOLO (Object detection)
- ByteTrack (Multi-Object Tracking)
- OpenCV (Video Processing)

## Dataset

- SportsMOT (planned)
